# REVIEW A

# Review of PR #23009: local fixtures for outdated listings and cyclic build dependencies

This PR is already merged, so this is a retrospective review. I read the diff but did not build the code or run any tests.

## Summary
The PR removes network dependence on TestPyPI/PyPI from four tests. It does this with localhost fixtures: `PackseServer` for the `pip list --outdated` tests, and `FindLinksServer` plus `WheelBuilder` for the cyclic-build test. It also renames the index fixtures from `pip-compile-*.toml` to `default.toml` and `extra.toml` so `pip list` and `pip compile` can share them. The motivation is sound, because a TestPyPI 503 was breaking CI.

## What looks good
- **Cyclic build test:** the construction matches the scenario. `circular-two` is a wheel that requires `circular-one`. The sdist's `pyproject.toml` has `build-system.requires = ["circular-two"]`. Using `--no-index --find-links` makes the test fully hermetic.
- **Doc comment fix:** "`circular-one` was a runtime dependency" is corrected to "as a runtime dependency".
- **Removed arguments:** dropping `with_exclude_newer`, `--extra-index-url` and `--index-strategy unsafe-best-match` is correct, since only one source exists now.
- **Gating:** the `PackseServer` import is behind `#[cfg(feature = "test-python")]`, matching the gated tests. This follows the AGENTS.md rule to check the feature gates, and it avoids an unused-import warning when the feature is off.
- **Style:** the new tests follow the explicit-setup style in AGENTS.md, with no loops and no shared snapshots.

## Points to check
1. **Gate for the `pip list` tests.** They now use `test-python` instead of `test-pypi`. That is right if they only need managed Python 3.12 and no external network. The `test_context!("3.12")` call is what needs the interpreter, so this seems fine. The PR description says it was verified.
2. **Fixture coupling.** `default.toml` is now shared across `pip compile` and `pip list`. The added `anyio 3.0.0`, `idna 3.6` and `sniffio 1.3.1` entries could change the outcome of existing compile tests that resolve `anyio`. The PR reports the six resolver tests pass, which covers this. Still, a comment in the fixture noting that it is shared would help future editors.
3. **Rename churn.** The `name` field changed from `pip-compile-default` to `default-index`. If that name feeds into any snapshot or server-side naming, check that nothing outside the tests references it. The diff I saw does not show a problem.
4. **Duplicate coverage.** `list_outdated_columns` and `list_outdated_json` now set up identical fixtures. That is acceptable, since they cover different output formats, but a small shared setup could remove the duplication. AGENTS.md prefers explicit setup over helpers, so leaving it as is fits the repo's convention.
5. **Imports in `pip_install.rs`.** The diff shows no new imports for `WheelBuilder`, `write_tar_gz`, `FindLinksServer`, `File` and `fs`. They must already be imported there, and CI passing would confirm it.
6. **Cycle error snapshot.** The first snapshot, for the `--no-binary` failure, is unchanged apart from the arguments. Because the sdist now has a minimal `pyproject.toml` and a fake `circular_two` backend, the failure should come from cycle detection, not from a missing module. The PR description says the cycle is still detected, which is the key claim.

## Security and performance
There are no security concerns. The servers bind to loopback only, and the PR says socket tracing showed only loopback connections. Tests should also run faster and be less flaky without network round trips.

## Verdict
This is a good change that I would approve. The only suggestions are optional: a comment on the shared fixtures, and confirming the `test-python` gating holds on CI platforms where managed Python 3.12 is unavailable.
