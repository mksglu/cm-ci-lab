# REVIEW A

**Review of PR 23009: use local fixtures for outdated listings and cyclic build dependencies**

This PR is already merged. The change looks good, and I found no blocking issues.

**What it does**
- `cyclic_build_dependency` now builds two wheels and one sdist locally and serves them through `FindLinksServer`. That removes the dependency on TestPyPI and the 503 flake.
- The three `pip list --outdated` tests now use `PackseServer` fixtures instead of `test-pypi`.
- The index fixtures are renamed from `pip-compile-*` to `default`/`extra`, since they are now shared. All the `pip_compile` call sites are updated.
- It also fixes a doc comment typo: "was a runtime dependency" is now "as a runtime dependency".

**Positives**
- The tests are now hermetic, and the cycle scenario is still exercised end to end: `--no-binary` fails and the wheel install succeeds.
- Fixtures are set up explicitly in each test, as AGENTS.md prefers, with no hidden helpers and no loops.
- The feature gate moved from `test-pypi` to `test-python`. The `PackseServer` import is gated the same way, so there is no unused-import warning when the feature is off.

**Minor observations (non-blocking)**
1. In `list_outdated_columns` and `list_outdated_json`, `UV_DEFAULT_INDEX` is set with `with_env`. `list_outdated_index` instead sets `UV_INDEX_URL`. The inconsistency is harmless, but a short comment on why would help. Presumably the second test needs a legacy index-URL path that the CLI `--index-url` override can replace.
2. `with_env(..., index.index_url())` makes the whole context point at the local index, including the `pip install` step in each test. This is fine here, because `default.toml` gained `anyio 3.0.0`, `idna` and `sniffio` for that reason. Anyone changing those fixtures should know that other tests depend on them.
3. Renaming the shared fixtures means any future test that edits the `anyio` versions affects both the `pip_compile` tests and the `pip_list` tests. The versions that matter, 4.3.0 on the default index and 3.5.0 on the extra, are not documented in the TOML files. A one-line comment there would help.
4. `cyclic_build_dependency` has no `#[cfg(feature = ...)]` gate. That seems right, since it needs only localhost and a Python 3.13 interpreter. It still runs `test_context!("3.13")` without `test-python`, as the old test did, so there is no regression.
5. The test now creates files inline with `WheelBuilder` and `write_tar_gz`, which makes it longer. That is acceptable, because the inputs stay visible.

**Security and performance**
- No security concerns. The servers bind to loopback only, which the PR description says was verified by socket tracing.
- Performance should be better, since there are no network round-trips.

**Verdict:** LGTM. The only suggestions are optional comments documenting the fixture versions the tests rely on.
