# CANDIDATE A

## Highlights

- MCP servers on private enterprise networks can now use OAuth when you opt in with `oauth.allowPrivateNetwork`.
- The terminal UI flickers less, especially in tmux, and keeps your scrollback during refreshes.
- Several fixes make updates, git operations, keybindings and settings more reliable.

## New Features

- Add an opt-in `oauth.allowPrivateNetwork` setting so MCP OAuth flows can reach private network endpoints. [#29844](https://github.com/google-gemini/gemini-cli/pull/29844)
- Reduce screen flicker, including in tmux, by using synchronized terminal output and rendering spinners separately. [#29725](https://github.com/google-gemini/gemini-cli/pull/29725)

## Bug Fixes

- Keep terminal scrollback when the viewport refreshes. [#29792](https://github.com/google-gemini/gemini-cli/pull/29792)
- Fix debug console height and flickering in the terminal buffer. [#29695](https://github.com/google-gemini/gemini-cli/pull/29695)
- Stop the right-hand border from bleeding into scrollable tool output. [#29742](https://github.com/google-gemini/gemini-cli/pull/29742)
- Accept a `keys` array in `keybindings.json`. [#29773](https://github.com/google-gemini/gemini-cli/pull/29773)
- Resolve settings placeholders after `.env` files are loaded. [#29750](https://github.com/google-gemini/gemini-cli/pull/29750)
- Check the active binary after an update so a shadowed PATH entry no longer reports a false success. [#29757](https://github.com/google-gemini/gemini-cli/pull/29757)
- Forward termination signals from the launcher process to the child process. [#29790](https://github.com/google-gemini/gemini-cli/pull/29790)
- Show slash-command conflict warnings again when conflicts reappear. [#29768](https://github.com/google-gemini/gemini-cli/pull/29768)
- Parse single-line descriptions in `SKILL.md` frontmatter more reliably. [#29769](https://github.com/google-gemini/gemini-cli/pull/29769)
- Round durations before choosing units so they display correctly. [#29766](https://github.com/google-gemini/gemini-cli/pull/29766)
- Quote and format diff command arguments correctly when opening a diff on Windows. [#29753](https://github.com/google-gemini/gemini-cli/pull/29753)
- Keep your user-level `~/.gitconfig` in shell and git environments. [#29832](https://github.com/google-gemini/gemini-cli/pull/29832)
- Disable interactive credential and SSH prompts in git commands run by the CLI. [#29760](https://github.com/google-gemini/gemini-cli/pull/29760)
- Avoid false positives when detecting authentication errors. [#29835](https://github.com/google-gemini/gemini-cli/pull/29835)
- Decode streamed HTTP activity chunks correctly so multi-byte characters aren't corrupted. [#29827](https://github.com/google-gemini/gemini-cli/pull/29827)

## Other

- Add a README banner saying Gemini CLI isn't optimized for Gemini 4, and remove obsolete README content. [#29774](https://github.com/google-gemini/gemini-cli/pull/29774), [#29775](https://github.com/google-gemini/gemini-cli/pull/29775)
- Update the roadmap to drop outdated 2025 references. [#29723](https://github.com/google-gemini/gemini-cli/pull/29723)
- Refactor the scheduler to emit tool call groups directly and remove the UI lookahead. [#29736](https://github.com/google-gemini/gemini-cli/pull/29736)
- Move gsutil usage to `gcloud storage`. [#29839](https://github.com/google-gemini/gemini-cli/pull/29839)
- Fix the unassign-inactive-assignees workflow. [#29770](https://github.com/google-gemini/gemini-cli/pull/29770)
- Add the v0.64.0 and v0.65.0-preview.0 changelogs and release version bumps. [#29741](https://github.com/google-gemini/gemini-cli/pull/29741), [#29739](https://github.com/google-gemini/gemini-cli/pull/29739)

# CANDIDATE B

## Highlights

- MCP servers can now opt in to OAuth on private enterprise networks with the new `oauth.allowPrivateNetwork` setting. ([#29844](https://github.com/google-gemini/gemini-cli/pull/29844))
- Smoother terminal rendering: synchronized output, isolated spinner rendering, and preserved scrollback.
- A README banner now notes that Gemini CLI is not optimized for Gemini 4. ([#29774](https://github.com/google-gemini/gemini-cli/pull/29774))

## Features

- Added `oauth.allowPrivateNetwork` for MCP servers, allowing OAuth discovery, registration, and token exchange on private networks (RFC 1918, RFC 6598, RFC 4193, `.internal`, `.local`). It is off by default. ([#29844](https://github.com/google-gemini/gemini-cli/pull/29844))
- `keybindings.json` now accepts a `keys` array to bind several keys to one command. ([#29773](https://github.com/google-gemini/gemini-cli/pull/29773))

## Bug fixes

- Fixed flicker and spinner redraw problems using synchronized output. ([#29725](https://github.com/google-gemini/gemini-cli/pull/29725))
- Fixed debug console height and terminal buffer flickering. ([#29695](https://github.com/google-gemini/gemini-cli/pull/29695))
- Fixed the right-hand border bleeding into scrollable tool containers. ([#29742](https://github.com/google-gemini/gemini-cli/pull/29742))
- Terminal scrollback is now preserved during viewport refreshes. ([#29792](https://github.com/google-gemini/gemini-cli/pull/29792))
- Fixed durations being formatted with the wrong unit due to rounding order. ([#29766](https://github.com/google-gemini/gemini-cli/pull/29766))
- Fixed settings placeholders so they resolve after `.env` files are loaded. ([#29750](https://github.com/google-gemini/gemini-cli/pull/29750))
- Hardened `SKILL.md` frontmatter parsing for single-line descriptions. ([#29769](https://github.com/google-gemini/gemini-cli/pull/29769))
- Git commands run by the CLI no longer prompt for credentials or SSH input. ([#29760](https://github.com/google-gemini/gemini-cli/pull/29760))
- Your user-level `~/.gitconfig` is now preserved in shell and git environments. ([#29832](https://github.com/google-gemini/gemini-cli/pull/29832))
- Fixed Windows diff command arguments being formatted and quoted incorrectly. ([#29753](https://github.com/google-gemini/gemini-cli/pull/29753))
- Fixed false-positive authentication error detection. ([#29835](https://github.com/google-gemini/gemini-cli/pull/29835))
- Update checks now verify the active binary, avoiding false success when another install shadows it on PATH. ([#29757](https://github.com/google-gemini/gemini-cli/pull/29757))
- Slash-command conflict warnings now reappear when conflicts return. ([#29768](https://github.com/google-gemini/gemini-cli/pull/29768))
- Termination signals are now forwarded from the bootstrap parent to the child process. ([#29790](https://github.com/google-gemini/gemini-cli/pull/29790))
- Fixed decoding of streamed HTTP activity chunks. ([#29827](https://github.com/google-gemini/gemini-cli/pull/29827))

## Other

- Scheduler now emits tool call groups, removing the UI lookahead. ([#29736](https://github.com/google-gemini/gemini-cli/pull/29736))
- Migrated `gsutil` usage to `gcloud storage`. ([#29839](https://github.com/google-gemini/gemini-cli/pull/29839))
- CI: removed an unsupported permission from the unassign-inactive-assignees workflow. ([#29770](https://github.com/google-gemini/gemini-cli/pull/29770))
- Docs: README cleanup, ROADMAP update, changelog updates. ([#29775](https://github.com/google-gemini/gemini-cli/pull/29775), [#29723](https://github.com/google-gemini/gemini-cli/pull/29723))
- Release version bumps.

**Full changelog**: https://github.com/google-gemini/gemini-cli/compare/v0.65.0...v0.66.0
