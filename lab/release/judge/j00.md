# CANDIDATE A

## Highlights

- Telemetry can now send custom OTLP headers, so you can export to authenticated backends such as Grafana Cloud, Honeycomb or Datadog.
- Safer handling of untrusted folders: workspace settings there are now read-only.
- Many fixes for sessions, authentication, input handling and terminal rendering.

## New features

- Set custom OTLP headers for telemetry in settings, in `OTEL_EXPORTER_OTLP_HEADERS` or `GEMINI_TELEMETRY_OTLP_HEADERS`, or on the command line. [#29641](https://github.com/google-gemini/gemini-cli/pull/29641)

## Security

- Workspace settings are now read-only in untrusted folders. [#29583](https://github.com/google-gemini/gemini-cli/pull/29583)
- Fewer false positives when flagging untrusted command flags and compound loops. [#29672](https://github.com/google-gemini/gemini-cli/pull/29672)
- OAuth callback `iss` parameter validation now follows RFC 9207 metadata. [#29616](https://github.com/google-gemini/gemini-cli/pull/29616)

## Bug fixes

### Sessions and conversation

- Rapidly pressing Ctrl-C no longer corrupts the session. [#29728](https://github.com/google-gemini/gemini-cli/pull/29728)
- Quitting quickly after resuming a session no longer deletes its history. [#29584](https://github.com/google-gemini/gemini-cli/pull/29584)
- Resuming a session no longer produces duplicate tool response turns. [#29618](https://github.com/google-gemini/gemini-cli/pull/29618)
- Requests now always end on a valid user turn, and request contents are normalized. [#29612](https://github.com/google-gemini/gemini-cli/pull/29612)
- The text of `ask_user` questions is kept in the tool result display. [#29677](https://github.com/google-gemini/gemini-cli/pull/29677)

### Authentication

- Verification and OAuth retries no longer loop forever. [#29655](https://github.com/google-gemini/gemini-cli/pull/29655)
- Re-selecting Google login now clears cached credentials. [#29643](https://github.com/google-gemini/gemini-cli/pull/29643)

### Interface and input

- Fixed a hang when pressing Enter in interactive mode. [#29476](https://github.com/google-gemini/gemini-cli/pull/29476)
- Expanding with Ctrl+O no longer clears the terminal or resets scrolling unnecessarily. [#29640](https://github.com/google-gemini/gemini-cli/pull/29640)
- The static UI refreshes again, with debouncing, when the terminal width changes. [#29644](https://github.com/google-gemini/gemini-cli/pull/29644)
- Reverse search now highlights the correct position for characters that expand, such as some unicode. [#29699](https://github.com/google-gemini/gemini-cli/pull/29699)
- `@<directory>` references no longer eagerly read the whole directory. [#29617](https://github.com/google-gemini/gemini-cli/pull/29617)

### Extensions, files and tools

- One extension failing the allowlist check no longer stops other extensions from loading. [#29720](https://github.com/google-gemini/gemini-cli/pull/29720)
- Whitespace-only UTF-16 and UTF-32 files are treated as empty. [#29722](https://github.com/google-gemini/gemini-cli/pull/29722)
- Truncating text now preserves line terminators. [#29673](https://github.com/google-gemini/gemini-cli/pull/29673)
- JSON parse and response stream errors in `fetchJson` are now handled. [#29658](https://github.com/google-gemini/gemini-cli/pull/29658)
- In the A2A server, rejecting a tool call now affects only that call in sequential batches. [#29683](https://github.com/google-gemini/gemini-cli/pull/29683)
- The VS Code companion's `IdeServer.stop()` now finishes even while MCP sessions are open. [#29674](https://github.com/google-gemini/gemini-cli/pull/29674)

## Performance

- Faster ignore-file filtering, with pruning of ignored subtrees. [#29582](https://github.com/google-gemini/gemini-cli/pull/29582)

## Other

- Fixed a missing loop in the unassign-inactive-assignees workflow. [#29609](https://github.com/google-gemini/gemini-cli/pull/29609)
- Added changelogs for v0.63.0 and v0.64.0-preview.0. [#29659](https://github.com/google-gemini/gemini-cli/pull/29659), [#29656](https://github.com/google-gemini/gemini-cli/pull/29656)
- Version bumps and release housekeeping.

**Full changelog:** https://github.com/google-gemini/gemini-cli/compare/v0.64.0...v0.65.0


# CANDIDATE B

## Highlights

- Telemetry can now send custom OTLP headers, so you can export to authenticated collectors and services.
- `@<directory>` references no longer read every nested file into your prompt.
- Workspace settings are now protected from being overwritten in untrusted folders.
- Fixes for login loops, session resume and history, and interactive input hangs.

## New Features

- Added custom OTLP headers for telemetry via the `telemetry.otlpHeaders` setting or `GEMINI_TELEMETRY_OTLP_HEADERS` (JSON or `key=value` pairs; falls back to `OTEL_EXPORTER_OTLP_HEADERS`) ([#29641](https://github.com/google-gemini/gemini-cli/pull/29641)).

## Improvements

- `@<directory>` now passes the directory path to the model instead of eagerly reading all files inside it ([#29617](https://github.com/google-gemini/gemini-cli/pull/29617)).
- Ignore-file filtering is faster, and ignored subtrees are now skipped during file discovery ([#29582](https://github.com/google-gemini/gemini-cli/pull/29582)).

## Bug Fixes

### Authentication
- Stopped endless browser-verification and OAuth retry loops; verification now retries a limited number of times ([#29655](https://github.com/google-gemini/gemini-cli/pull/29655)).
- Re-selecting Google login now clears cached credentials ([#29643](https://github.com/google-gemini/gemini-cli/pull/29643)).
- OAuth callback `iss` validation now follows RFC 9207 server metadata ([#29616](https://github.com/google-gemini/gemini-cli/pull/29616)).

### Settings, trust and extensions
- Workspace settings are now read-only in untrusted folders, so commands like `gemini mcp add` and `gemini mcp remove` can't overwrite them ([#29583](https://github.com/google-gemini/gemini-cli/pull/29583)).
- One extension failing the allowlist check no longer stops other extensions from loading ([#29720](https://github.com/google-gemini/gemini-cli/pull/29720)).
- Fixed false positives when flagging untrusted command flags and compound loops ([#29672](https://github.com/google-gemini/gemini-cli/pull/29672)).

### Sessions and conversation
- Fixed resumed session history being deleted when you quit quickly ([#29584](https://github.com/google-gemini/gemini-cli/pull/29584)).
- Fixed duplicate tool-response turns when resuming sessions ([#29618](https://github.com/google-gemini/gemini-cli/pull/29618)).
- Requests now always end on a valid user turn, avoiding malformed conversation history ([#29612](https://github.com/google-gemini/gemini-cli/pull/29612)).
- Rapid Ctrl-C interruptions no longer corrupt the session ([#29728](https://github.com/google-gemini/gemini-cli/pull/29728)).
- `ask_user` question text is now kept in the tool result display ([#29677](https://github.com/google-gemini/gemini-cli/pull/29677)).

### Terminal UI and input
- Fixed a hang when pressing Enter in interactive mode ([#29476](https://github.com/google-gemini/gemini-cli/pull/29476)).
- Expanding with Ctrl+O no longer causes needless terminal clears or scroll resets ([#29640](https://github.com/google-gemini/gemini-cli/pull/29640)).
- Restored the debounced UI refresh when the terminal width changes ([#29644](https://github.com/google-gemini/gemini-cli/pull/29644)).
- Fixed reverse-search highlighting for characters that expand, such as some Unicode ([#29699](https://github.com/google-gemini/gemini-cli/pull/29699)).

### Files and network
- Whitespace-only UTF-16 and UTF-32 files are now treated as empty ([#29722](https://github.com/google-gemini/gemini-cli/pull/29722)).
- Line terminators are now preserved when text is truncated ([#29673](https://github.com/google-gemini/gemini-cli/pull/29673)).
- JSON parse and response stream errors are now handled when fetching extension data ([#29658](https://github.com/google-gemini/gemini-cli/pull/29658)).

### IDE and A2A
- The VS Code companion's server now stops cleanly even while MCP sessions are open ([#29674](https://github.com/google-gemini/gemini-cli/pull/29674)).
- In the A2A server, rejecting a tool now affects only the active call in sequential batches ([#29683](https://github.com/google-gemini/gemini-cli/pull/29683)).

## Deprecations, Removals and Breaking Changes

- None.

- Added changelogs for v0.63.0 and v0.64.0-preview.0 ([#29659](https://github.com/google-gemini/gemini-cli/pull/29659), [#29656](https://github.com/google-gemini/gemini-cli/pull/29656)).
- Release version bumps and nightly/preview releases.
