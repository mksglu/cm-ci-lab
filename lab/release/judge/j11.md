## PUBLISHED RELEASE NOTES (written by the maintainers)

[Sponsorship is appreciated!](https://github.com/sponsors/BurntSushi/)

This release fixes a number of bugs related to gitignore matching as well as
some performance improvements in directory tree traversal.

> In case you haven't heard of it before, ripgrep is a line-oriented search
> tool that recursively searches the current directory for a regex pattern.
> By default, ripgrep will respect gitignore rules and automatically skip
> hidden files/directories and binary files.

Platform support:

* `aarch64-unknown-linux-musl` is now included in the release binaries for
  ripgrep.

Performance improvements:

* [PERF #3293](https://github.com/BurntSushi/ripgrep/issues/3293):
  Improves directory traversal time on very large corpora.

Feature enhancements:

* [FEATURE #3275](https://github.com/BurntSushi/ripgrep/issues/3275):
  ripgrep now respects `GIT_CONFIG_GLOBAL` and `GIT_CONFIG_SYSTEM`.

Bug fixes:

* [BUG #3212](https://github.com/BurntSushi/ripgrep/pull/3212):
  Don't check for the existence of `.jj` when `--no-ignore` is used.
* [BUG #3320](https://github.com/BurntSushi/ripgrep/pull/3419),
  [BUG #3376](https://github.com/BurntSushi/ripgrep/pull/3376),
  [BUG #3419](https://github.com/BurntSushi/ripgrep/pull/3419):
  Fix gitignore matching bug when searching across multiple directories.

# CANDIDATE A

ripgrep 15.2.0 adds several file types, fixes ignore-file handling when searching multiple paths, and speeds up directory walking. It also honors git's `GIT_CONFIG_GLOBAL` and `GIT_CONFIG_SYSTEM` variables and greatly improves zsh completions.

## Bug fixes

* Fix parent `.gitignore`/`.rgignore` rules being applied wrongly when searching several paths at once. [#3419](https://github.com/BurntSushi/ripgrep/issues/3419), [#3320](https://github.com/BurntSushi/ripgrep/issues/3320), [#3376](https://github.com/BurntSushi/ripgrep/issues/3376)
* Respect `GIT_CONFIG_GLOBAL` and `GIT_CONFIG_SYSTEM` when looking up `core.excludesFile`. [#3275](https://github.com/BurntSushi/ripgrep/issues/3275), [#3276](https://github.com/BurntSushi/ripgrep/pull/3276)
* Also read `core.excludesFile` from the system git config (`/etc/gitconfig` by default). [#3276](https://github.com/BurntSushi/ripgrep/pull/3276)
* Fix `-g`/`--glob` matching logic where a set of globs could wrongly report that all globs matched. [#3290](https://github.com/BurntSushi/ripgrep/issues/3290), [#3302](https://github.com/BurntSushi/ripgrep/pull/3302)

## Performance

* Read each directory's entries in one batch when looking for ignore files, which is much faster on Windows and noticeably faster on Linux. [#3293](https://github.com/BurntSushi/ripgrep/issues/3293), [#3410](https://github.com/BurntSushi/ripgrep/pull/3410)
* Skip checking for a `.jj` directory when ignore rules are disabled. [#3212](https://github.com/BurntSushi/ripgrep/pull/3212)
* Hint sequential access when searching memory-mapped files (memory maps remain off on macOS). [#3246](https://github.com/BurntSushi/ripgrep/pull/3246)
* Copy fewer paths in glob matching. [#3454](https://github.com/BurntSushi/ripgrep/pull/3454)

## New file types

* Add `container` type covering `Dockerfile` and `Containerfile`. [#3271](https://github.com/BurntSushi/ripgrep/pull/3271)
* Add `hurl` type. [#3444](https://github.com/BurntSushi/ripgrep/pull/3444)
* Add `PKGBUILD` type. [#3299](https://github.com/BurntSushi/ripgrep/issues/3299)
* Add `.v` files to the Rocq type (formerly Coq). [#3357](https://github.com/BurntSushi/ripgrep/issues/3357)
* Add `proto` type for protobuf files. [#3445](https://github.com/BurntSushi/ripgrep/issues/3445)
* Add `mojo` type for `*.mojo` files. [#3440](https://github.com/BurntSushi/ripgrep/issues/3440)

## Improvements

* Add a debug log message when `RIPGREP_CONFIG_PATH` is not set, so no config file is read.
* Clarify the `-w/--word-regexp` documentation about half-boundary syntax.
* Improve zsh completions: add missing options and groups, use number completion for numeric flags (needs zsh 5.9+), and improve color-spec and type-spec completion.
* Fix typos in the man page and docs. [#3216](https://github.com/BurntSushi/ripgrep/pull/3216), [#3227](https://github.com/BurntSushi/ripgrep/pull/3227), [#3446](https://github.com/BurntSushi/ripgrep/pull/3446)

## Library changes

These affect users of the `ignore` and `globset` crates.

* `ignore`: add `WalkBuilder::empty` and `WalkBuilder::from_iter`. [#1761](https://github.com/BurntSushi/ripgrep/issues/1761), [#3261](https://github.com/BurntSushi/ripgrep/pull/3261)
* `ignore`: errors from directory walking now always include their depth, which could affect callers that downcast nested errors. [#3453](https://github.com/BurntSushi/ripgrep/issues/3453), [#3464](https://github.com/BurntSushi/ripgrep/pull/3464)

## Other

* Add release builds and tests for `aarch64-unknown-linux-musl`. [#2739](https://github.com/BurntSushi/ripgrep/issues/2739)
* Add `AI_POLICY.md` and `CONTRIBUTING.md`.
* Raise the minimum `termcolor` version to 1.4.0. [#3308](https://github.com/BurntSushi/ripgrep/pull/3308)
* Update dependencies, including `tikv-jemallocator` 0.7.0.
* Fix compression tests under QEMU cross-compilation. [#3248](https://github.com/BurntSushi/ripgrep/pull/3248)
* Add multi-root ignore regression tests, clippy cleanups, and other internal refactors. [#3230](https://github.com/BurntSushi/ripgrep/pull/3230), [#3451](https://github.com/BurntSushi/ripgrep/pull/3451)
* Release new crate versions: `ignore` 0.4.29, `globset` 0.4.19, `grep-searcher` 0.1.17, `grep-pcre2` 0.1.10, `grep-matcher` 0.1.9.


# CANDIDATE B

ripgrep 15.2.0 is a small release with bug fixes for gitignore handling, faster directory walking, a few new file types and updated zsh completions.

**Bug fixes:**

* Fix parent `.gitignore` rules being applied incorrectly when searching multiple paths. [#3419](https://github.com/BurntSushi/ripgrep/issues/3419)
* Fix `.gitignore` files above a Git repository boundary sometimes being read. [#3451](https://github.com/BurntSushi/ripgrep/pull/3451)
* Respect `GIT_CONFIG_GLOBAL` and `GIT_CONFIG_SYSTEM` when looking up `core.excludesFile`. [#3276](https://github.com/BurntSushi/ripgrep/pull/3276)
* Read the system-level git config (`/etc/gitconfig` by default) for `core.excludesFile`, which was previously ignored. [#3276](https://github.com/BurntSushi/ripgrep/pull/3276)
* Fix a bug in `globset` where `matches_all` could report a match when not every glob matched. [#3302](https://github.com/BurntSushi/ripgrep/pull/3302)

**Performance improvements:**

* Speed up directory traversal by reading each directory's entries in one batch to find ignore files, which helps most on Windows. [#3410](https://github.com/BurntSushi/ripgrep/pull/3410)
* Stop checking for a `.jj` directory when ignore rules that need it are disabled (for example, with `--no-ignore`). [#3212](https://github.com/BurntSushi/ripgrep/pull/3212)
* Hint to the OS that memory-mapped files are read sequentially on Unix. [#3246](https://github.com/BurntSushi/ripgrep/pull/3246)
* Copy fewer paths when matching globs. [#3454](https://github.com/BurntSushi/ripgrep/issues/3454)

**Feature enhancements:**

* Add `container` file type covering `Dockerfile` and `Containerfile` names. [#3271](https://github.com/BurntSushi/ripgrep/pull/3271)
* Add `hurl` file type for `*.hurl` files. [#3444](https://github.com/BurntSushi/ripgrep/pull/3444)
* Add `mojo` file type for `*.mojo` files. [#3440](https://github.com/BurntSushi/ripgrep/pull/3440)
* Add `pkgbuild` file type for `PKGBUILD` files. [#3299](https://github.com/BurntSushi/ripgrep/pull/3299)
* Add `proto` as a shorter alias for the `protobuf` file type. [#3445](https://github.com/BurntSushi/ripgrep/pull/3445)
* Add `rocq` file type for `*.v` files, and keep `coq` as is. [#3357](https://github.com/BurntSushi/ripgrep/pull/3357)
* Print a debug message (with `--debug`) when `RIPGREP_CONFIG_PATH` is not set.
* Improve and fix many zsh completions, including type and colour specs.

**Library changes (`ignore` and `globset` crates):**

* Add `WalkBuilder::empty` and `WalkBuilder::from_iter` for building a walker without an initial path. [#3261](https://github.com/BurntSushi/ripgrep/pull/3261)
* Include the directory depth in more walk errors, including I/O errors. This could affect callers that downcast nested errors. [#3453](https://github.com/BurntSushi/ripgrep/issues/3453), [#3464](https://github.com/BurntSushi/ripgrep/pull/3464)

**Other:**

* Clarify the `-w/--word-regexp` docs on the half-boundary syntax it uses.
* Fix typos in the man page, flag docs, guide and code comments.
* Add release artifacts and CI testing for `aarch64-unknown-linux-musl`. [#2739](https://github.com/BurntSushi/ripgrep/issues/2739)
* Fix compression tests under QEMU cross-compilation, and re-enable them on riscv64. [#3248](https://github.com/BurntSushi/ripgrep/pull/3248)
* Add `CONTRIBUTING.md` and an AI policy, and update the guide to use `lexopt`.
* Raise the minimum `termcolor` version to 1.4.0. [#3308](https://github.com/BurntSushi/ripgrep/pull/3308)
* Update dependencies, including `tikv-jemallocator` 0.7.0, and apply lint fixes.
* Add regression tests for multi-root ignore matching and release new `ignore`, `globset`, `grep-matcher`, `grep-pcre2` and `grep-searcher` crate versions.
