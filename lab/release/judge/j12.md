## Verifying GitHub Artifact Attestations

The artifacts in this release have attestations generated with GitHub Artifact Attestations. These can be verified by using the [GitHub CLI](https://cli.github.com/manual/gh_attestation_verify):
```sh
gh attestation verify <file-path of downloaded artifact> --repo astral-sh/ruff
```

You can also download the attestation from [GitHub](https://github.com/astral-sh/ruff/attestations) and verify against that directly:
```sh
gh attestation verify <file-path of downloaded artifact> --bundle <file-path of downloaded attestation>
```

# Ruff 0.17.1

Released on 2026-10-31.

## Release Notes

### Bug fixes

- Fix unsafe fixes that dedent code when there are multiple leading comments ([#29382](https://github.com/astral-sh/ruff/pull/29382))
- \[`flake8-pyi`\] Stop flagging quoted annotations in `bad-exit-annotation` (`PYI036`) ([#29274](https://github.com/astral-sh/ruff/pull/29274))
- \[`flake8-pyi`\] Check the parameter after the receiver in `__new__` methods for `PYI063` ([#28502](https://github.com/astral-sh/ruff/pull/28502))
- \[`perflint`\] Avoid suggesting invalid comprehensions when the iterable is a ternary or lambda (`PERF401`, `PERF403`) ([#29366](https://github.com/astral-sh/ruff/pull/29366))
- \[`pycodestyle`\] Stop treating `None`, `True` and `False` as keywords (`E271`–`E274`) ([#29322](https://github.com/astral-sh/ruff/pull/29322))

### Rule changes

- Treat `weakref.WeakKeyDictionary`, `WeakValueDictionary`, `WeakSet` and `collections.ChainMap`, `UserDict`, `UserList`, `UserString` as mutable, so `B006` now reports them as mutable argument defaults instead of `B008` ([#29213](https://github.com/astral-sh/ruff/pull/29213))
  - This also affects other rules that check for mutable values, such as `B039`, `RUF008`, `RUF012`, `RUF024` and `PLW2901`.

### Documentation

- \[`flake8-import-conventions`\] Update the default and example `aliases` in the docs ([#29333](https://github.com/astral-sh/ruff/pull/29333))
- Document Ruff release code signing ([#29265](https://github.com/astral-sh/ruff/pull/29265))

### Other changes

- Ruff 0.17.1 also includes many type-checking improvements for [ty](https://github.com/astral-sh/ty), which is released separately.
- Use the workspace `rand` and `rust-version` in `ruff_unicode_names2` ([#29261](https://github.com/astral-sh/ruff/pull/29261))
- Use thin LTO for PGO training ([#29271](https://github.com/astral-sh/ruff/pull/29271))
- Use a shared time budget for fuzzing ([#29280](https://github.com/astral-sh/ruff/pull/29280))
- Pin Python for the `py-fuzzer` and scripts CI checks ([#29370](https://github.com/astral-sh/ruff/pull/29370))
- Update the referenced PR security-review workflow ([#29237](https://github.com/astral-sh/ruff/pull/29237))
- Update Rust and npm dependencies, `uv`, `prek` and other tooling

## Contributors

See the [0.17.1 milestone](https://github.com/astral-sh/ruff/pulls?q=is%3Apr+milestone%3A0.17.1) for the full list of changes.
