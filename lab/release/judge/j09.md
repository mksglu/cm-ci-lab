## PUBLISHED RELEASE NOTES (written by the maintainers)

[Sponsorship is appreciated!](https://github.com/sponsors/BurntSushi/)

This is a minor release with a bug fix for a matching bug. In particular, a bug
was found that could cause ripgrep to ignore lines that should match. That is,
false negatives. It is difficult to characterize the specific set of regexes
in which this occurs as it requires multiple different optimization strategies
to collide and produce an incorrect result. But as one reported example, in
ripgrep, the regex `(?i:e.x|ex)` does not match `e-x` when it should. (This
bug is a result of an inner literal optimization performed in the `grep-regex`
crate and not in the `regex` crate.)

> In case you haven't heard of it before, ripgrep is a line-oriented search
> tool that recursively searches the current directory for a regex pattern.
> By default, ripgrep will respect gitignore rules and automatically skip
> hidden files/directories and binary files.

Bug fixes:

* [BUG #2884](https://github.com/BurntSushi/ripgrep/issues/2884):
  Fix bug where ripgrep could miss some matches that it should report.

Miscellaneous:

* [MISC #2748](https://github.com/BurntSushi/ripgrep/issues/2748):
  Remove ripgrep's `simd-accel` feature because it was frequently broken.

# CANDIDATE A

ripgrep 14.1.1 is a patch release with a bug fix for missed matches, a fix for searching process substitution, and a few small additions.

**Bug fixes:**

* Fix a bug where some case-insensitive patterns such as `(?i:e.x|ex)` could miss matches, for example failing to match `e-x`. [#2884](https://github.com/BurntSushi/ripgrep/issues/2884)
* Fix searching a single path that is not a regular file, such as process substitution (`<(...)`), which was previously not treated as a file. [#2736](https://github.com/BurntSushi/ripgrep/issues/2736)
* Fix ripgrep failing to compile on platforms that are neither Unix nor Windows, such as WASI. Hyperlink support is disabled on those platforms.

**Feature enhancements:**

* Add `svelte`, `vue` and `wgsl` to the default file types. [#2759](https://github.com/BurntSushi/ripgrep/pull/2759), [#2772](https://github.com/BurntSushi/ripgrep/pull/2772), [#2774](https://github.com/BurntSushi/ripgrep/pull/2774)
* Add debug log messages (`--debug`) showing which gitignore files are opened, and how ripgrep decides whether to search stdin.
* Update the bundled PCRE2 to 10.43.

**Removals:**

* Remove the `simd-accel` Cargo feature, which was frequently broken. UTF-16 transcoding now uses scalar code only. [#2748](https://github.com/BurntSushi/ripgrep/issues/2748)

**Other:**

* Reduce heap allocations when escaping characters in the `globset` crate. [#2833](https://github.com/BurntSushi/ripgrep/pull/2833)
* Fix typos and improve docs, including `--heading`, `--vimgrep`, `--hidden` and `--engine=auto`. [#2864](https://github.com/BurntSushi/ripgrep/pull/2864), [#2802](https://github.com/BurntSushi/ripgrep/pull/2802), [#2718](https://github.com/BurntSushi/ripgrep/pull/2718), [#2850](https://github.com/BurntSushi/ripgrep/pull/2850), [#2776](https://github.com/BurntSushi/ripgrep/pull/2776), [#2754](https://github.com/BurntSushi/ripgrep/pull/2754), [#2741](https://github.com/BurntSushi/ripgrep/pull/2741)
* Fix the ugrep benchmark command in the docs. [#2876](https://github.com/BurntSushi/ripgrep/pull/2876)
* Add Flox as an installation method and update the Debian link and the unofficial playground link. [#2817](https://github.com/BurntSushi/ripgrep/pull/2817), [#2829](https://github.com/BurntSushi/ripgrep/pull/2829), [#2760](https://github.com/BurntSushi/ripgrep/pull/2760)
* Fix the `ignore` crate's `build_parallel()` docs. [#2767](https://github.com/BurntSushi/ripgrep/issues/2767)
* Remove the unused man page template; generate the man page with `rg --generate man`. [#2801](https://github.com/BurntSushi/ripgrep/issues/2801)
* Update dependencies (Windows builds now use `windows-sys` instead of `winapi`), add a WASI CI check, add a FUNDING file and tweak the issue template.
* Release new versions of the `globset`, `ignore`, `grep-cli`, `grep-regex`, `grep-pcre2`, `grep-searcher`, `grep-printer` and `grep` crates.


# CANDIDATE B

ripgrep 14.1.1 is a patch release with a few bug fixes, new file types and dependency updates.

## Bug fixes

- Fixed a case where some case-insensitive alternations, such as `(?i:e.x|ex)`, could miss matches (for example, failing to match `e-x`). [#2884](https://github.com/BurntSushi/ripgrep/issues/2884)
- A single file passed through process substitution (a FIFO, e.g. `rg foo <(cmd)`) is now treated as a file. [#2736](https://github.com/BurntSushi/ripgrep/issues/2736)
- Fixed compilation on platforms that are neither Unix nor Windows, such as WASI. Hyperlink support is disabled there.

## Feature enhancements

- Added `svelte` to the default file types. [#2759](https://github.com/BurntSushi/ripgrep/pull/2759)
- Added `vue` to the default file types. [#2772](https://github.com/BurntSushi/ripgrep/pull/2772)
- Added `wgsl` to the default file types. [#2774](https://github.com/BurntSushi/ripgrep/pull/2774)
- `--debug` output now says which gitignore files are opened and explains how ripgrep decides whether to search stdin. [#2806](https://github.com/BurntSushi/ripgrep/issues/2806)

## Other

- Removed the `simd-accel` Cargo feature, so UTF-16 transcoding now uses scalar code. [#2748](https://github.com/BurntSushi/ripgrep/issues/2748)
- PCRE2 updated to 10.43, and dependencies updated, including the move from `winapi` to `windows-sys`.
- Reduced allocations when escaping characters in `globset`.
- Docs: fixed typos in `--hidden`, `--heading` and `--vimgrep` help, the `--engine=auto` flag reference and a benchmark command; added Flox and playground links and updated the Debian link; corrected the `build_parallel()` docs; removed the unused man page template. [#2718](https://github.com/BurntSushi/ripgrep/pull/2718) [#2802](https://github.com/BurntSushi/ripgrep/pull/2802) [#2850](https://github.com/BurntSushi/ripgrep/pull/2850) [#2864](https://github.com/BurntSushi/ripgrep/pull/2864) [#2876](https://github.com/BurntSushi/ripgrep/pull/2876) [#2817](https://github.com/BurntSushi/ripgrep/pull/2817) [#2829](https://github.com/BurntSushi/ripgrep/pull/2829) [#2767](https://github.com/BurntSushi/ripgrep/issues/2767) [#2801](https://github.com/BurntSushi/ripgrep/issues/2801)
- Project housekeeping: added a WASI CI check, a FUNDING file and an updated bug report template; updated the Homebrew tap; fixed new lints.
- Bumped the internal crates `globset`, `ignore`, `grep`, `grep-cli`, `grep-pcre2`, `grep-printer`, `grep-regex` and `grep-searcher`.
