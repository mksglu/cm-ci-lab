# CANDIDATE A

## Highlights

- MCP servers can now opt in to OAuth on private enterprise networks.
- Terminal rendering is smoother, with less flicker and scrollback preserved.
- A new banner tells users Gemini CLI is not yet optimized for Gemini 4.

## New Features

- Added the `oauth.allowPrivateNetwork` option so MCP servers and OAuth endpoints on private networks (such as RFC 1918 ranges, `.internal` and `.local`) can be used when you enable it in `settings.json`. [#29844](https://github.com/google-gemini/gemini-cli/pull/29844)
- `keybindings.json` entries now accept a `keys` array, so one entry can bind or unbind several key combinations. [#29773](https://github.com/google-gemini/gemini-cli/pull/29773)
- Added a banner noting that Gemini CLI is not optimized for Gemini 4. [#29774](https://github.com/google-gemini/gemini-cli/pull/29774)

## Bug Fixes

- Fixed a custom keybindings file being discarded entirely when it used an array of keys. [#29773](https://github.com/google-gemini/gemini-cli/pull/29773)
- Auto-update no longer reports success when an older copy of the CLI earlier in your `PATH` is still the one running. [#29757](https://github.com/google-gemini/gemini-cli/pull/29757)
- Settings placeholders (such as environment variables) are now resolved after `.env` files are loaded. [#29750](https://github.com/google-gemini/gemini-cli/pull/29750)
- Your user-level `~/.gitconfig` is now kept when the CLI runs shell and git commands. [#29832](https://github.com/google-gemini/gemini-cli/pull/29832)
- Git commands run by the CLI no longer stop to ask for credentials or SSH passwords. [#29760](https://github.com/google-gemini/gemini-cli/pull/29760)
- Fixed false positives when detecting authentication errors. [#29835](https://github.com/google-gemini/gemini-cli/pull/29835)
- Termination signals are now passed from the launcher process to the CLI process. [#29790](https://github.com/google-gemini/gemini-cli/pull/29790)
- Terminal scrollback is now preserved when the viewport refreshes. [#29792](https://github.com/google-gemini/gemini-cli/pull/29792)
- Reduced flicker by using synchronized output and rendering the spinner separately. [#29725](https://github.com/google-gemini/gemini-cli/pull/29725)
- Fixed the debug console height and flickering in the terminal buffer. [#29695](https://github.com/google-gemini/gemini-cli/pull/29695)
- Fixed the right-hand border bleeding into scrollable tool output. [#29742](https://github.com/google-gemini/gemini-cli/pull/29742)
- Slash-command conflict notices now reappear when conflicts come back. [#29768](https://github.com/google-gemini/gemini-cli/pull/29768)
- Skills with single-line descriptions in `SKILL.md` frontmatter are now parsed more reliably. [#29769](https://github.com/google-gemini/gemini-cli/pull/29769)
- Fixed durations being shown with the wrong unit because of rounding. [#29766](https://github.com/google-gemini/gemini-cli/pull/29766)
- Fixed opening diffs on Windows by quoting command arguments correctly. [#29753](https://github.com/google-gemini/gemini-cli/pull/29753)
- Fixed garbled streamed HTTP activity output caused by split characters. [#29827](https://github.com/google-gemini/gemini-cli/pull/29827)

## Other

- Grouping of consecutive sub-agent calls is now decided by the scheduler instead of the UI. [#29736](https://github.com/google-gemini/gemini-cli/pull/29736)
- Moved gsutil usage to `gcloud storage`. [#29839](https://github.com/google-gemini/gemini-cli/pull/29839)
- Fixed an unsupported permission in the unassign-inactive-assignees workflow. [#29770](https://github.com/google-gemini/gemini-cli/pull/29770)
- Updated the README, the roadmap and the changelogs. [#29775](https://github.com/google-gemini/gemini-cli/pull/29775), [#29723](https://github.com/google-gemini/gemini-cli/pull/29723), [#29741](https://github.com/google-gemini/gemini-cli/pull/29741), [#29739](https://github.com/google-gemini/gemini-cli/pull/29739)

**Full changelog**: https://github.com/google-gemini/gemini-cli/compare/v0.65.0...v0.66.0


# CANDIDATE B

## Highlights

- MCP servers can now opt in to private-network OAuth endpoints with `oauth.allowPrivateNetwork`.
- The terminal UI is smoother: less flicker, and scrollback is kept when the view refreshes.
- Many fixes for settings, keybindings, skills, auto-update, and git environments.
- The README now says Gemini CLI isn't optimized for the latest Gemini models, and points to Antigravity CLI.

## New Features

- Allow MCP OAuth flows to reach private-network endpoints (RFC 1918, CGNAT, IPv6 unique-local, `.internal` and `.local`) when you set `oauth.allowPrivateNetwork` for a server. It is off by default. [#29844](https://github.com/google-gemini/gemini-cli/pull/29844)
- Accept a `keys` array for a binding in `keybindings.json`. [#29773](https://github.com/google-gemini/gemini-cli/pull/29773)

## Bug Fixes

- Fix cases where terminal scrollback was lost when the viewport refreshed. [#29792](https://github.com/google-gemini/gemini-cli/pull/29792)
- Reduce flicker by using synchronized output and rendering the spinner separately. [#29725](https://github.com/google-gemini/gemini-cli/pull/29725)
- Fix the debug console height and flickering in the terminal buffer. [#29695](https://github.com/google-gemini/gemini-cli/pull/29695)
- Stop the right-hand border from bleeding into scrollable tool output. [#29742](https://github.com/google-gemini/gemini-cli/pull/29742)
- Resolve placeholders in settings after `.env` files are loaded. [#29750](https://github.com/google-gemini/gemini-cli/pull/29750)
- Parse `SKILL.md` frontmatter more reliably when the description is on a single line. [#29769](https://github.com/google-gemini/gemini-cli/pull/29769)
- Keep your user-level `~/.gitconfig` working in shell and git commands. [#29832](https://github.com/google-gemini/gemini-cli/pull/29832)
- Turn off interactive credential and SSH prompts in git commands run by the CLI, so they don't hang. [#29760](https://github.com/google-gemini/gemini-cli/pull/29760)
- Avoid false "authentication error" detections on unrelated errors. [#29835](https://github.com/google-gemini/gemini-cli/pull/29835)
- Check that the active `gemini` binary was really updated, so an older copy earlier on your PATH no longer causes a false "update succeeded" message. [#29757](https://github.com/google-gemini/gemini-cli/pull/29757)
- Pass termination signals from the launcher process to the child CLI process. [#29790](https://github.com/google-gemini/gemini-cli/pull/29790)
- Show slash-command conflict warnings again when a conflict comes back. [#29768](https://github.com/google-gemini/gemini-cli/pull/29768)
- Fix durations that were rounded incorrectly when units were chosen. [#29766](https://github.com/google-gemini/gemini-cli/pull/29766)
- Quote diff command arguments correctly when opening an external diff on Windows. [#29753](https://github.com/google-gemini/gemini-cli/pull/29753)
- Fix garbled streamed HTTP activity logs when multi-byte characters are split across chunks. [#29827](https://github.com/google-gemini/gemini-cli/pull/29827)

## Other

- Remove the UI lookahead for tool calls. The scheduler now emits tool call groups directly. [#29736](https://github.com/google-gemini/gemini-cli/pull/29736)
- Update the README: add notices about Antigravity CLI and Gemini 4, and remove outdated content. [#29774](https://github.com/google-gemini/gemini-cli/pull/29774), [#29775](https://github.com/google-gemini/gemini-cli/pull/29775)
- Update ROADMAP.md to stop referencing the outdated 2025 roadmap. [#29723](https://github.com/google-gemini/gemini-cli/pull/29723)
- Add changelogs for v0.64.0 and v0.65.0-preview.0. [#29741](https://github.com/google-gemini/gemini-cli/pull/29741), [#29739](https://github.com/google-gemini/gemini-cli/pull/29739)
- Move `gsutil` usage to `gcloud storage`. [#29839](https://github.com/google-gemini/gemini-cli/pull/29839)
- Fix the unassign-inactive-assignees workflow by removing an unsupported permission. [#29770](https://github.com/google-gemini/gemini-cli/pull/29770)
- Release version bumps for v0.66.0 and v0.66.0-preview.0.

**Full changelog**: https://github.com/google-gemini/gemini-cli/compare/v0.65.0...v0.66.0
