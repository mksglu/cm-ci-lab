## Verifying GitHub Artifact Attestations

The artifacts in this release have attestations generated with GitHub Artifact Attestations. These can be verified by using the [GitHub CLI](https://cli.github.com/manual/gh_attestation_verify):
```sh

```

You can also download the attestation from [GitHub](https://github.com/astral-sh/ruff/attestations) and verify against that directly:
```sh
gh attestation verify <file-path of downloaded artifact> --bundle <file-path of downloaded attestation>
```

# Release Notes

## Released on 2026-10-30

This release contains bug fixes and documentation updates. It has no breaking changes, deprecations, or removals.

### Rule changes

- \[`flake8-bugbear`\] Report `weakref.WeakKeyDictionary`, `weakref.WeakValueDictionary`, `weakref.WeakSet`, `collections.ChainMap`, `collections.UserDict`, `collections.UserList` and `collections.UserString` as mutable defaults under `B006` instead of `B008` ([#29213](https://github.com/astral-sh/ruff/pull/29213))
- \[`flake8-pyi`\] Skip the `__new__` receiver and check the next parameter in `PYI063` ([#28502](https://github.com/astral-sh/ruff/pull/28502))
- \[`flake8-pyi`\] Stop `PYI036` from flagging quoted annotations that are equivalent to the correct unquoted form ([#29274](https://github.com/astral-sh/ruff/pull/29274))
- \[`pycodestyle`\] Stop `E271`–`E274` from flagging whitespace around `None`, `True` and `False` ([#29322](https://github.com/astral-sh/ruff/pull/29322))
- \[`perflint`\] Parenthesize ternary and lambda iterables in the `PERF401` and `PERF403` fixes, and skip the fix when the iterable contains an assignment expression, so the fix no longer produces invalid code ([#29366](https://github.com/astral-sh/ruff/pull/29366))

### Bug fixes

- Fix a bug in fixes that dedent code when several comments precede the first line of code ([#29382](https://github.com/astral-sh/ruff/pull/29382))

### Documentation

- \[`flake8-import-conventions`\] Update the default and example `aliases` in the docs, including the `networkx` → `nx` default ([#29333](https://github.com/astral-sh/ruff/pull/29333))
- Document Ruff release code signing ([#29265](https://github.com/astral-sh/ruff/pull/29265))

### Other changes

- Fix notebook cell offset handling in the parser, which also fixes ty panics and wrong positions in notebooks ([#29306](https://github.com/astral-sh/ruff/pull/29306), [#29307](https://github.com/astral-sh/ruff/pull/29307), [#29308](https://github.com/astral-sh/ruff/pull/29308))
- ty: include many type-checking fixes and improvements, and enable `invalid-mutable-override` by default ([#29335](https://github.com/astral-sh/ruff/pull/29335))
- Maintenance: update dependencies, use thin LTO for PGO training, share a time budget in fuzzing, pin Python in CI checks, and refresh the release and security-review workflows ([#29271](https://github.com/astral-sh/ruff/pull/29271), [#29280](https://github.com/astral-sh/ruff/pull/29280), [#29370](https://github.com/astral-sh/ruff/pull/29370), [#29237](https://github.com/astral-sh/ruff/pull/29237), [#29261](https://github.com/astral-sh/ruff/pull/29261))
