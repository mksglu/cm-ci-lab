# CANDIDATE A

## Fixes

- Arrays, sets and maps now check `.max()`, `.length()` and `.size()` before parsing elements, so an oversized input reports one size issue instead of one issue per bad element. Fixes #6643. (#6652)
- Fixed `z.json()` reporting error TS5115 and inferring a record input of `any` on newer TypeScript builds. (#6645)

## Other

- Docs: import locales from `zod/locales` rather than `z.locales`, which bundles every locale under esbuild and Turbopack, and load `en` directly in Zod Mini.
- Docs: added Code for Japan to the bronze sponsors.
- Release workflow: npm versions are now staged for maintainer approval rather than published directly, and the approval wait no longer holds a runner. (#6622, #6638)


# CANDIDATE B

## Fixes

- Array, set and map size checks (`.max()`, `.length()`, `.size()`) now run before the elements are parsed, so an oversized input is rejected right away instead of producing one issue per bad element. Applies to both the standard and compiled paths. ([#6652](https://github.com/colinhacks/zod/pull/6652), fixes [#6643](https://github.com/colinhacks/zod/issues/6643))
- Fixed a TypeScript error (TS5115) and an `any` record input type on `z.json()` with newer TypeScript builds. ([#6645](https://github.com/colinhacks/zod/pull/6645))

## Other

- Docs: import locales from `zod/locales` instead of `z.locales` to avoid bundling every locale, including in Zod Mini.
- Docs: added Code for Japan to the bronze sponsors.
- Release workflow now stages npm versions for approval instead of publishing directly. ([#6622](https://github.com/colinhacks/zod/pull/6622), [#6638](https://github.com/colinhacks/zod/pull/6638))
