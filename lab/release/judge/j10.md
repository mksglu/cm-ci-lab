This release fixes a number of bugs related to gitignore matching as well as
some performance improvements in directory tree traversal.

> In case you haven't heard of it before, ripgrep is a line-oriented search
> tool that recursively searches the current directory for a regex pattern.
> By default, ripgrep will respect gitignore rules and automatically skip
> hidden files/directories and binary files.

  Improves directory traversal time on very large corpora.

Feature enhancements:

* [FEATURE #3275](https://github.com/BurntSushi/ripgrep/issues/3275):
  ripgrep now respects `GIT_CONFIG_GLOBAL` and `GIT_CONFIG_SYSTEM`.

Bug fixes:

* [BUG #3212](https://github.com/BurntSushi/ripgrep/pull/3212):
  Don't check for the existence of `.jj` when `--no-ignore` is used.
* [BUG #3320](https://github.com/BurntSushi/ripgrep/pull/3419),
  [BUG #3376](https://github.com/BurntSushi/ripgrep/pull/3376),
  [BUG #3419](https://github.com/BurntSushi/ripgrep/pull/3419):
  Fix gitignore matching bug when searching across multiple directories.

# CANDIDATE A

ripgrep 15.2.0 is a small release with faster directory traversal, a few ignore-handling fixes, new file types and better zsh completions.

## Performance

* Directory traversal is faster, especially on Windows, because ripgrep now reads directory entries in batches to find ignore files. [#3410](https://github.com/BurntSushi/ripgrep/pull/3410)
* ripgrep no longer checks for a `.jj` directory when you have turned off ignore rules (for example with `--no-ignore`).  [#3212](https://github.com/BurntSushi/ripgrep/pull/3212)
* Memory-mapped files are now read with a sequential-access hint on Unix. [#3246](https://github.com/BurntSushi/ripgrep/pull/3246)

## Bug fixes

* Parent `.gitignore` and `.rgignore` rules are now applied correctly when you search several paths in one command. [#3419](https://github.com/BurntSushi/ripgrep/issues/3419)
* ripgrep now honors `GIT_CONFIG_GLOBAL` and `GIT_CONFIG_SYSTEM` when finding the global `core.excludesFile`, and also reads the system git config (`/etc/gitconfig` by default). [#3276](https://github.com/BurntSushi/ripgrep/pull/3276)
* Glob matching with `matches_all` no longer wrongly reports a match when several globs share a strategy. [#3302](https://github.com/BurntSushi/ripgrep/pull/3302)
* Some error messages now include the directory depth where the error happened. [#3464](https://github.com/BurntSushi/ripgrep/pull/3464)

## New file types

* Added `container`, which matches both `Dockerfile` and `Containerfile` files. [#3271](https://github.com/BurntSushi/ripgrep/pull/3271)
* Added `hurl` for `*.hurl` files. [#3444](https://github.com/BurntSushi/ripgrep/pull/3444)
* Added `mojo` for `*.mojo` files. [#3440](https://github.com/BurntSushi/ripgrep/pull/3440)
* Added `pkgbuild` for `PKGBUILD` files. [#3299](https://github.com/BurntSushi/ripgrep/pull/3299)
* Added `rocq` for Rocq `*.v` files. The `coq` type is still available. [#3357](https://github.com/BurntSushi/ripgrep/pull/3357)
* Added `proto` as a short name for the `protobuf` type. [#3445](https://github.com/BurntSushi/ripgrep/pull/3445)

## Other improvements

* With `RIPGREP_CONFIG_PATH` unset, `--debug` now says that no config file is being read.
* The `-w/--word-regexp` documentation now explains the `\b{start-half}` and `\b{end-half}` syntax.
* The zsh completions have been cleaned up, with better completion for colour specs, type specs, encodings and hyperlink formats, and fixes to option groups.

## Library crates

* `ignore` gained `WalkBuilder::empty` and `WalkBuilder::from_iter`. [#3261](https://github.com/BurntSushi/ripgrep/pull/3261)
* `globset` copies fewer paths while matching. [#3454](https://github.com/BurntSushi/ripgrep/pull/3454)
* Released `globset` 0.4.19, `ignore` 0.4.29, `grep-matcher` 0.1.9, `grep-pcre2` 0.1.10 and `grep-searcher` 0.1.17.

## Other

* Added prebuilt binaries and CI testing for `aarch64-unknown-linux-musl`.
* Added `CONTRIBUTING.md` and an AI policy for contributors; updated the GUIDE to use `lexopt`.
* Fixed several typos in docs and comments, and made small lint cleanups. [#3446](https://github.com/BurntSushi/ripgrep/pull/3446)
* Raised the minimum `termcolor` version to 1.4.0 and updated dependencies, including `tikv-jemallocator` 0.7.0. [#3308](https://github.com/BurntSushi/ripgrep/pull/3308)
* Fixed compression tests under QEMU cross-compilation. [#3248](https://github.com/BurntSushi/ripgrep/pull/3248)
* Added regression tests for multi-root ignore handling, and improved the zsh completion tests.


# CANDIDATE B

ripgrep 15.2.0 is a small release with gitignore fixes, a faster directory walk, a few new file types and a new Linux release target.

## Bug fixes

* Fixed a bug where searching several paths could apply a parent `.gitignore` or `.rgignore` rule relative to the wrong path. [#3419](https://github.com/BurntSushi/ripgrep/issues/3419)
* ripgrep now honors the `GIT_CONFIG_GLOBAL` and `GIT_CONFIG_SYSTEM` environment variables when it looks up `core.excludesFile`. [#3275](https://github.com/BurntSushi/ripgrep/issues/3275), [#3276](https://github.com/BurntSushi/ripgrep/pull/3276)
* ripgrep now also reads `core.excludesFile` from the system-wide git config (`/etc/gitconfig` by default), at the lowest priority. [#3276](https://github.com/BurntSushi/ripgrep/pull/3276)
* Fixed `matches_all` in the `globset` library, which could report that all globs matched when some had not. [#3290](https://github.com/BurntSushi/ripgrep/issues/3290), [#3302](https://github.com/BurntSushi/ripgrep/pull/3302)
* Errors from walking directories now include the depth in the directory tree.

## Performance improvements

* Directory walking is faster because ripgrep now reads each directory's entries once instead of checking for ignore files one path at a time. This is especially noticeable on Windows. [#3293](https://github.com/BurntSushi/ripgrep/issues/3293), [#3410](https://github.com/BurntSushi/ripgrep/pull/3410)
* ripgrep no longer looks for a `.jj` directory when `--no-ignore` or a similar flag makes it unnecessary. [#3212](https://github.com/BurntSushi/ripgrep/pull/3212)
* Memory-mapped files are now read with a sequential access hint on Unix. [#3246](https://github.com/BurntSushi/ripgrep/pull/3246)
* The `globset` library copies fewer paths while matching. [#3454](https://github.com/BurntSushi/ripgrep/issues/3454)

## Feature enhancements

* Added the `container` file type, which covers `Dockerfile` and `Containerfile` files.
* Added the `hurl` file type. [#3444](https://github.com/BurntSushi/ripgrep/pull/3444)
* Added the `mojo` file type for `*.mojo` files. [#3440](https://github.com/BurntSushi/ripgrep/issues/3440)
* Added the `pkgbuild` file type for `PKGBUILD` files. [#3299](https://github.com/BurntSushi/ripgrep/pull/3299)
* Added the `rocq` file type for `*.v` files. The existing `coq` type still works. [#3357](https://github.com/BurntSushi/ripgrep/issues/3357)
* Added `proto` as a short name for the `protobuf` file type. [#3445](https://github.com/BurntSushi/ripgrep/issues/3445)
* Running ripgrep with debug logging now says when `RIPGREP_CONFIG_PATH` is not set, so no config file is read. [#3277](https://github.com/BurntSushi/ripgrep/issues/3277)
* The `ignore` library has new `WalkBuilder::empty` and `WalkBuilder::from_iter` methods. [#1761](https://github.com/BurntSushi/ripgrep/issues/1761), [#3261](https://github.com/BurntSushi/ripgrep/pull/3261)

## Platform support

* Release builds now include `aarch64-unknown-linux-musl`.

## Other

* Improved the zsh completion script: more accurate option groups, better completion of colour specs, type specs, encodings and hyperlink formats, and an updated completion test.
* Expanded the `-w/--word-regexp` documentation to explain the half-boundary syntax it uses.
* Fixed several typos in the man page, docs and code comments.
* Added `AI_POLICY.md` and `CONTRIBUTING.md`, and updated the GUIDE to refer to `lexopt`.
* Raised the minimum `termcolor` version to 1.4.0, updated `tikv-jemallocator` to 0.7.0 and refreshed other dependencies.
* Added regression tests for gitignore matching across multiple roots and fixed compression tests under QEMU. [#3248](https://github.com/BurntSushi/ripgrep/pull/3248)
* Made small internal cleanups, including derived `Default` impls and clippy lint fixes.
* Released `ignore` 0.4.29, `globset` 0.4.19, `grep-matcher` 0.1.9, `grep-pcre2` 0.1.10 and `grep-searcher` 0.1.17.
