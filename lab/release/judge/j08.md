## PUBLISHED RELEASE NOTES (written by the maintainers)

[Sponsorship is appreciated!](https://github.com/sponsors/BurntSushi/)

This is a minor release with a bug fix for a matching bug. In particular, a bug
was found that could cause ripgrep to ignore lines that should match. That is,
false negatives. It is difficult to characterize the specific set of regexes
in which this occurs as it requires multiple different optimization strategies
to collide and produce an incorrect result. But as one reported example, in
ripgrep, the regex `(?i:e.x|ex)` does not match `e-x` when it should. (This
bug is a result of an inner literal optimization performed in the `grep-regex`
crate and not in the `regex` crate.)

> In case you haven't heard of it before, ripgrep is a line-oriented search
> tool that recursively searches the current directory for a regex pattern.
> By default, ripgrep will respect gitignore rules and automatically skip
> hidden files/directories and binary files.

Bug fixes:

* [BUG #2884](https://github.com/BurntSushi/ripgrep/issues/2884):
  Fix bug where ripgrep could miss some matches that it should report.

Miscellaneous:

* [MISC #2748](https://github.com/BurntSushi/ripgrep/issues/2748):
  Remove ripgrep's `simd-accel` feature because it was frequently broken.

# CANDIDATE A

ripgrep 14.1.1 is a patch release with a few bug fixes, new file types, and dependency updates.

## Bug fixes

- Fixed a bug where some case-insensitive patterns such as `(?i:e.x|ex)` could miss matches, e.g. `e-x`. ([#2884](https://github.com/BurntSushi/ripgrep/issues/2884))
- A single file argument that is not a regular file, such as one from process substitution (a fifo), is now treated as a file. ([#2736](https://github.com/BurntSushi/ripgrep/issues/2736))
- Fixed building ripgrep on platforms that are neither Unix nor Windows, such as WASI. Hyperlink support is disabled there.

## Feature enhancements

- Added the `svelte` file type. ([#2759](https://github.com/BurntSushi/ripgrep/pull/2759))
- Added the `vue` file type. ([#2772](https://github.com/BurntSushi/ripgrep/pull/2772))
- Added the `wgsl` file type. ([#2774](https://github.com/BurntSushi/ripgrep/pull/2774))
- `--debug` output now logs when a gitignore file is opened, which helps show where ignore rules come from.
- `--debug` output now logs more detail about how ripgrep decides whether to search stdin. ([#2806](https://github.com/BurntSushi/ripgrep/issues/2806))

## Build and packaging changes

- Removed the `simd-accel` Cargo feature, which was frequently broken. UTF-16 transcoding now uses only scalar code. ([#2748](https://github.com/BurntSushi/ripgrep/issues/2748))
- PCRE2 was updated to 10.43.
- Man page generation is done by `rg --generate man`. The unused `doc/rg.1.txt.tpl` template was removed. ([#2801](https://github.com/BurntSushi/ripgrep/issues/2801))
- The Windows build now uses `windows-sys` instead of `winapi`.

## Other

- Updated the `grep`, `grep-cli`, `grep-pcre2`, `grep-printer`, `grep-regex`, `grep-searcher`, `globset` and `ignore` crates, and bumped many other dependencies.
- Reduced heap allocations when escaping characters in `globset`. ([#2833](https://github.com/BurntSushi/ripgrep/pull/2833))
- Fixed the `ignore` docs for `build_parallel()`. ([#2767](https://github.com/BurntSushi/ripgrep/issues/2767))
- Documentation fixes: typos in `--hidden`, `--vimgrep` and `--heading` help and elsewhere ([#2718](https://github.com/BurntSushi/ripgrep/pull/2718), [#2754](https://github.com/BurntSushi/ripgrep/pull/2754), [#2776](https://github.com/BurntSushi/ripgrep/pull/2776), [#2802](https://github.com/BurntSushi/ripgrep/pull/2802), [#2864](https://github.com/BurntSushi/ripgrep/pull/2864)), the `--engine=auto` flag name ([#2850](https://github.com/BurntSushi/ripgrep/pull/2850)), the ugrep benchmark command ([#2876](https://github.com/BurntSushi/ripgrep/pull/2876)), the Debian install link ([#2829](https://github.com/BurntSushi/ripgrep/pull/2829)), and the man page date.
- Added Flox as an installation method ([#2817](https://github.com/BurntSushi/ripgrep/pull/2817)) and a link to an unofficial playground ([#2760](https://github.com/BurntSushi/ripgrep/pull/2760)).
- CI, issue template, FUNDING file, lint and Homebrew tap updates, plus a basic WASI CI test.
