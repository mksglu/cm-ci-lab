# CANDIDATE A

## Highlights

- Telemetry can now send custom OTLP headers, so you can export to authenticated collectors such as Grafana Cloud, Honeycomb or Datadog.
- Several session, authentication and input-handling bugs are fixed, including hangs, retry loops and lost session history.
- `@<directory>` references are lighter and no longer read every nested file into your prompt.

## New features

- Added support for custom OTLP headers in telemetry. Set `telemetry.otlpHeaders` in settings, or use `OTEL_EXPORTER_OTLP_HEADERS` or `GEMINI_TELEMETRY_OTLP_HEADERS`, for both HTTP and gRPC exporters ([#29641](https://github.com/google-gemini/gemini-cli/pull/29641)).

## Behavior changes

- `@<directory>` now passes the directory path to the model, which can list or inspect it with its tools, instead of eagerly reading every nested file ([#29617](https://github.com/google-gemini/gemini-cli/pull/29617)).
- Workspace settings are now read-only in untrusted folders, and `gemini mcp add` and `gemini mcp remove` refuse to change project settings there. Use `--scope user` or trust the workspace ([#29583](https://github.com/google-gemini/gemini-cli/pull/29583)).

## Bug fixes

### Sessions and conversation
- Fixed resumed session history being deleted when you quit quickly ([#29584](https://github.com/google-gemini/gemini-cli/pull/29584)).
- Fixed duplicate tool-response turns when resuming a session ([#29618](https://github.com/google-gemini/gemini-cli/pull/29618)).
- Fixed requests that could end on a non-user turn or contain malformed contents ([#29612](https://github.com/google-gemini/gemini-cli/pull/29612)).
- Fixed a session becoming unusable after rapid repeated Ctrl-C interruptions ([#29728](https://github.com/google-gemini/gemini-cli/pull/29728)).

### Authentication
- Fixed infinite verification and OAuth retry loops ([#29655](https://github.com/google-gemini/gemini-cli/pull/29655)).
- Fixed cached credentials not being cleared when you pick Google login again ([#29643](https://github.com/google-gemini/gemini-cli/pull/29643)).
- Aligned OAuth callback `iss` validation with RFC 9207 server metadata ([#29616](https://github.com/google-gemini/gemini-cli/pull/29616)).

### Interface and input
- Fixed a hang when pressing Enter in interactive mode ([#29476](https://github.com/google-gemini/gemini-cli/pull/29476)).
- Fixed unnecessary terminal clears and scroll resets when expanding with Ctrl+O ([#29640](https://github.com/google-gemini/gemini-cli/pull/29640)).
- Restored the debounced UI refresh when the terminal width changes ([#29644](https://github.com/google-gemini/gemini-cli/pull/29644)).
- Fixed the reverse-search highlight position for characters that expand, such as some Unicode ([#29699](https://github.com/google-gemini/gemini-cli/pull/29699)).
- Kept the `ask_user` question text in the displayed tool result ([#29677](https://github.com/google-gemini/gemini-cli/pull/29677)).

### Tools, files and extensions
- Reduced false positives when checking untrusted command flags and compound loops ([#29672](https://github.com/google-gemini/gemini-cli/pull/29672)).
- Whitespace-only UTF-16 and UTF-32 files are now treated as empty ([#29722](https://github.com/google-gemini/gemini-cli/pull/29722)).
- Line terminators are now preserved when text is truncated ([#29673](https://github.com/google-gemini/gemini-cli/pull/29673)).
- A single extension failing the allowlist check no longer stops other extensions from loading ([#29720](https://github.com/google-gemini/gemini-cli/pull/29720)).
- Fetching JSON now handles parse and response-stream errors gracefully ([#29658](https://github.com/google-gemini/gemini-cli/pull/29658)).

### IDE and A2A
- The VS Code companion's server now stops cleanly even while MCP sessions are open ([#29674](https://github.com/google-gemini/gemini-cli/pull/29674)).
- The A2A server now limits a tool rejection to the active call in sequential batches ([#29683](https://github.com/google-gemini/gemini-cli/pull/29683)).

## Performance

- Faster file ignore filtering, with subtree pruning ([#29582](https://github.com/google-gemini/gemini-cli/pull/29582)).

## Deprecations, removals and breaking changes

- None.

## Other

- Fixed a missing loop in the unassign-inactive-assignees workflow ([#29609](https://github.com/google-gemini/gemini-cli/pull/29609)).
- Added changelogs for v0.63.0 and v0.64.0-preview.0 ([#29659](https://github.com/google-gemini/gemini-cli/pull/29659), [#29656](https://github.com/google-gemini/gemini-cli/pull/29656)).
- Version bumps and release housekeeping ([#29657](https://github.com/google-gemini/gemini-cli/pull/29657)).

**Full changelog**: https://github.com/google-gemini/gemini-cli/compare/v0.64.0...v0.65.0


# CANDIDATE B

## Highlights

- Telemetry can now send custom OTLP headers, so you can export to authenticated collectors such as Grafana Cloud, Honeycomb or Datadog.
- Workspace settings in untrusted folders are now read-only, and several false-positive command warnings are gone.
- Many fixes for session resume, authentication loops, Ctrl-C handling and terminal display.

## New features

- Add custom OTLP headers to the telemetry configuration, as a JSON object or `key=value` pairs. [#29641](https://github.com/google-gemini/gemini-cli/pull/29641)

## Security

- Enforce read-only workspace settings in untrusted folders. [#29583](https://github.com/google-gemini/gemini-cli/pull/29583)
- Check the OAuth callback `iss` parameter in line with RFC 9207 metadata. [#29616](https://github.com/google-gemini/gemini-cli/pull/29616)
- Remove false positives when flagging untrusted command flags and compound loops. [#29672](https://github.com/google-gemini/gemini-cli/pull/29672)

- Ensure requests always end with a user turn and normalize request contents. [#29612](https://github.com/google-gemini/gemini-cli/pull/29612)
- Prevent a session from being corrupted when you press Ctrl-C rapidly. [#29728](https://github.com/google-gemini/gemini-cli/pull/29728)

### Authentication

- Prevent infinite verification and OAuth retry loops. [#29655](https://github.com/google-gemini/gemini-cli/pull/29655)
- Clear cached credentials when you select Google login again. [#29643](https://github.com/google-gemini/gemini-cli/pull/29643)

### Interface

- Fix a hang when pressing Enter in interactive mode. [#29476](https://github.com/google-gemini/gemini-cli/pull/29476)
- Avoid unnecessary terminal clears and scroll resets when expanding with Ctrl+O. [#29640](https://github.com/google-gemini/gemini-cli/pull/29640)
- Restore the debounced UI refresh when the terminal width changes. [#29644](https://github.com/google-gemini/gemini-cli/pull/29644)
- Fix the reverse-search highlight position for characters that expand, such as some Unicode. [#29699](https://github.com/google-gemini/gemini-cli/pull/29699)

### Files and extensions
